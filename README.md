# 📚 하루 다섯 사자성어

사자성어를 처음 배우는 **초등학교 저학년**을 위한 카드 학습 웹앱입니다.
서버 없이 HTML/CSS/JS 파일만으로 동작하므로 **GitHub Pages**에 그대로 올려 쓸 수 있습니다.

## 학습 방식

- **하루 5장**: 쉬운 사자성어(동서남북, 춘하추동…)부터 시작해 20일 동안 100개를 배웁니다.
- **카드 뒤집기**: 앞면은 그림·한글·한자, 뒷면은 한자 훈음 / 글자 풀이 / 쉬운 뜻 / 예문.
- **🔊 읽어 주기**: 브라우저 음성(TTS)으로 사자성어와 뜻을 읽어 줍니다. 아직 글이 서툰 아이도 들으며 공부할 수 있어요.
- **오늘의 퀴즈**: 5장의 뜻을 모두 보면 퀴즈가 열립니다. 5문제 중 3개 이상 맞히면 도장을 받습니다.
- **다음 날 새 카드**: 오늘 공부를 마치면 다음 날(날짜가 바뀌면) 새 카드 5장이 열립니다. 하루를 건너뛰어도 진도는 밀리지 않습니다.
- **복습 / 헷갈려요**: 배운 카드를 다시 보고, 틀리거나 "한 번 더 볼래요"를 누른 카드만 모아 볼 수 있습니다.
- **도장판·별**: 공부한 날마다 도장, 맞힌 문제마다 별을 모읍니다.
- **보호자 메뉴**(도장판 탭 아래): 다음 날 카드 미리 열기, 기록 지우기.

학습 기록은 기기 브라우저의 `localStorage`에만 저장됩니다(서버 전송 없음). 기기·브라우저를 바꾸면 기록이 이어지지 않습니다.

## GitHub Pages로 배포하기

1. GitHub에서 새 저장소를 만듭니다 (예: `saja`).
2. 이 폴더를 올립니다.
   ```bash
   git remote add origin https://github.com/<아이디>/saja.git
   git push -u origin main
   ```
3. 저장소 **Settings → Pages → Build and deployment**에서
   Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 저장합니다.
4. 1~2분 뒤 `https://<아이디>.github.io/saja/` 주소로 접속합니다.
   태블릿·휴대폰에서는 "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다.

## 로컬에서 보기

`index.html`을 브라우저로 바로 열거나, 간단한 서버를 띄웁니다.

```bash
python -m http.server 8000
```

## 사자성어 추가·수정

`js/data.js`의 `RAW_IDIOMS` 배열을 고치면 됩니다. 한 줄이 카드 한 장이며, 5개가 하루 분량입니다.

```js
["한글", "漢字", "훈 음|훈 음|훈 음|훈 음", "글자 그대로 풀이", "쉬운 뜻", "예문 (사자성어 포함)", "그림 이모지"]
```

## 파일 구성

```
index.html      화면 뼈대
css/style.css   디자인
js/data.js      사자성어 100개 (쉬운 순서)
js/app.js       카드·퀴즈·복습·도장판 로직
```
